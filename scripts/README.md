# Scripts

Thư mục này chứa các script hỗ trợ phát triển, kiểm thử và vận hành local.

Ví dụ script có thể bao gồm:

- Bật/tắt local stack.
- Chạy toàn bộ test.
- Seed sample data.
- Tạo topic Kafka.
- Tạo OpenSearch index.

Script trong thư mục này phải an toàn, rõ ràng và tránh thao tác phá hủy dữ liệu nếu không có xác nhận cụ thể.
