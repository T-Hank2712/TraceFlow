# OpenAPI Contracts

Thư mục này chứa OpenAPI specs cho các nhóm API chính của TraceFlow.

OpenAPI specs được dùng để mô tả path, method, parameter, request body, response body, status code, error response và security scheme.

Các contract trong thư mục này phải đồng bộ với tài liệu ở `docs/04-api/` và implementation trong các service tương ứng.
