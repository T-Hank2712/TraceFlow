# Tools

Thư mục này chứa công cụ hỗ trợ phát triển TraceFlow.

Ví dụ công cụ có thể bao gồm generator, benchmark helper, schema validator, migration helper hoặc script kiểm tra contract.

Các tool trong thư mục này không phải runtime service chính, nhưng có thể hỗ trợ phát triển, kiểm thử và vận hành hệ thống.
