# Definition Of Done

Một thay đổi được xem là hoàn thành khi:

- Code chạy đúng theo yêu cầu.
- Test phù hợp đã được thêm hoặc cập nhật.
- Docs/API/schema liên quan đã được cập nhật.
- Không lộ secret.
- Log và error handling đủ để debug.
- Multi-tenancy không bị phá.
- Local stack hoặc test liên quan đã được xác minh.
