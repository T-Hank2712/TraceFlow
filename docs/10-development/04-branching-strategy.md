# Branching Strategy

## Branch chính

- `main`: trạng thái ổn định.
- `feature/*`: tính năng mới.
- `fix/*`: sửa lỗi.
- `docs/*`: thay đổi tài liệu.
- `chore/*`: thay đổi tooling hoặc cấu hình.

## Nguyên tắc

Branch nên nhỏ và bám theo một mục tiêu cụ thể. Thay đổi schema/API cần được review kỹ hơn thay đổi nội bộ.
