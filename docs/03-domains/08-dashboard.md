# Domain: Dashboard

Dashboard cung cấp số liệu tổng quan từ log.

## Metrics

- Total logs.
- Logs per second.
- Errors.
- Warnings.
- Error rate.
- Logs by service.
- Logs by level.
- Recent errors.
- Top error messages.

## Filter

- Workspace.
- Project.
- Environment.
- Time range.

## Nguyên tắc

Dashboard không thay thế search. Dashboard giúp phát hiện tình trạng bất thường, còn search giúp điều tra chi tiết.
