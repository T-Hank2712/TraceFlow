# Glossary

## Workspace

Không gian làm việc của một đội hoặc tổ chức.

## Project

Boundary dữ liệu log và search trong workspace.

## Application

Service hoặc app gửi log vào TraceFlow.

## API Key

Credential để application gửi log.

## Ingestion

Quá trình nhận log từ application.

## Processor

Worker xử lý log từ Kafka và index vào OpenSearch.

## DLQ

Dead Letter Queue, nơi lưu event xử lý lỗi sau khi retry thất bại.
