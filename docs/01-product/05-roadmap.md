# Roadmap

## Milestone 1 - Core Log Flow

Tập trung hoàn thành luồng log cốt lõi:

```text
Project -> Application -> API Key -> Log Ingestion -> Kafka -> Processor -> OpenSearch -> Search
```

## Milestone 2 - Reliability Và Product Depth

- Rate limiting.
- Retention policy.
- Dead Letter Queue.
- Alert rules.
- Email, Telegram, Slack hoặc Webhook notification.
- Saved searches.
- Usage tracking.
- API key rotation.
- Service-level dashboard.

## Milestone 3 - Advanced Observability

- OpenTelemetry integration.
- Distributed tracing nâng cao.
- Metrics ingestion.
- Live log streaming.
- Anomaly detection.
- Multi-tenant optimization.
- Horizontal scaling.
- Kubernetes deployment.
- Performance benchmark có báo cáo.
