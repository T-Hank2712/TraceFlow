# Configuration

TraceFlow cấu hình qua environment variables.

## Nhóm cấu hình

- Database.
- Kafka.
- OpenSearch.
- JWT.
- API key hashing.
- Rate limiting.
- Retention.
- Notification channels.

## Nguyên tắc

Mỗi biến môi trường phải có giá trị mẫu trong `.env.example` và tài liệu mô tả ý nghĩa, default, yêu cầu bảo mật.
