# TraceFlow Spike Benchmark

## Test Configuration

| Parameter     | Value                   |
| ------------- | ----------------------- |
| Scenario      | spike                   |
| Virtual Users | 50                      |
| Duration      | 5 minutes 30 seconds    |
| Endpoint      | POST /ingestion/v1/logs |
| Environment   | performance             |

## Thresholds

| Metric      | Threshold |
| ----------- | --------- |
| Error rate  | < 1%      |
| p95 latency | < 500 ms  |

## Results

| Metric         |         Result |
| -------------- | -------------: |
| Total requests |        660,914 |
| Throughput     | 2,002.73 req/s |
| p50 latency    |        7.93 ms |
| p90 latency    |        9.39 ms |
| p95 latency    |        9.99 ms |
| Error rate     |          0.00% |

## Threshold Evaluation

| Metric      |  Result | Status |
| ----------- | ------: | ------ |
| Error rate  |   0.00% | PASS   |
| p95 latency | 9.99 ms | PASS   |

## Observations

* Hệ thống xử lý **660.914 request** trong thời gian **5 phút 30 giây**, với tối đa **50 VUs**.
* Throughput đạt khoảng **2.002,73 req/s**.
* Độ trễ **p50 là 7,93 ms**, **p90 là 9,39 ms** và **p95 là 9,99 ms**.
* Tỷ lệ lỗi HTTP là **0,00%**, toàn bộ request đều nhận HTTP 200.
* Cả hai threshold về **error rate** và **p95 latency** đều đạt yêu cầu.
* So với `test-002`, spike throughput tăng mạnh và tail latency giảm rõ rệt.
