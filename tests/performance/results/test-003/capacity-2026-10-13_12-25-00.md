# TraceFlow Capacity Benchmark After Resource Upgrade

## Test Configuration

| Parameter   | Value                   |
| ----------- | ----------------------- |
| Scenario    | capacity                |
| Executor    | constant-arrival-rate   |
| Duration    | 2 minutes               |
| Endpoint    | POST /ingestion/v1/logs |
| Environment | performance             |
| Resource    | after resource upgrade  |

## Thresholds

| Metric      | Threshold |
| ----------- | --------- |
| Error rate  | < 1%      |
| p95 latency | < 500 ms  |

## Threshold Evaluation

| Target RPS | Error rate result | Error rate status | p95 latency result | p95 latency status |
| ---------: | ----------------: | ----------------- | -----------------: | ------------------ |
|      2,200 |             0.33% | PASS              |           40.36 ms | PASS               |
|      2,500 |             0.00% | PASS              |           16.79 ms | PASS               |
|      2,700 |             0.01% | PASS              |           21.30 ms | PASS               |
|      3,000 |             0.91% | PASS              |            8.13 ms | PASS               |

## Observations

* Các mốc **2.200 RPS**, **2.500 RPS**, **2.700 RPS** và **3.000 RPS** đều đạt threshold cấu hình hiện tại.
* Mốc **2.500 RPS** là mốc sạch nhất trong nhóm này: error rate **0,00%**, p95 latency **16,79 ms**.
* Mốc **2.700 RPS** vẫn rất ổn định với error rate **0,01%** và p95 latency **21,30 ms**.
* Mốc **3.000 RPS** vẫn PASS nhưng error rate đã lên **0,91%**, sát ngưỡng threshold **1%**.
* Mốc **3.000 RPS** có dropped iterations **5.391**, cao hơn rõ rệt các mốc thấp hơn, cho thấy đây là vùng gần giới hạn của bài test hiện tại.
* p95 latency ở mốc **3.000 RPS** vẫn thấp, nhưng error rate và dropped iterations cho thấy không nên xem đây là mốc ổn định sạch.

## Summary

Sau khi nâng resource, hệ thống đạt kết quả tốt ở các mốc capacity cao hơn. Mốc **2.500 RPS** có thể xem là stable clean capacity trong bộ kết quả này. Mốc **2.700 RPS** vẫn là upper passing capacity tốt. Mốc **3.000 RPS** còn PASS theo threshold nhưng đã sát giới hạn lỗi, nên phù hợp để xem là edge passing capacity hơn là mốc vận hành ổn định.
