# TraceFlow Load Benchmark

## Test Configuration

| Parameter     | Value                   |
| ------------- | ----------------------- |
| Scenario      | load                    |
| Virtual Users | 10                      |
| Duration      | 5 minutes               |
| Endpoint      | POST /ingestion/v1/logs |
| Environment   | performance             |

## Thresholds

| Metric      | Threshold |
| ----------- | --------- |
| Error rate  | < 1%      |
| p95 latency | < 500 ms  |

## Results

| Metric         |       Result |
| -------------- | -----------: |
| Total requests |      298,424 |
| Throughput     | 994.74 req/s |
| p50 latency    |      7.91 ms |
| p90 latency    |      9.28 ms |
| p95 latency    |      9.84 ms |
| Error rate     |        0.00% |

## Threshold Evaluation

| Metric      |  Result | Status |
| ----------- | ------: | ------ |
| Error rate  |   0.00% | PASS   |
| p95 latency | 9.84 ms | PASS   |

## Observations

* Hệ thống xử lý **298.424 request** trong thời gian **5 phút**, với tối đa **10 VUs**.
* Throughput đạt khoảng **994,74 req/s**.
* Độ trễ **p50 là 7,91 ms**, **p90 là 9,28 ms** và **p95 là 9,84 ms**.
* Tỷ lệ lỗi HTTP là **0,00%**, không có request thất bại.
* Cả hai threshold về **error rate** và **p95 latency** đều đạt yêu cầu.
* So với `test-002`, throughput tăng và p95 latency giảm trong cùng kịch bản load.
