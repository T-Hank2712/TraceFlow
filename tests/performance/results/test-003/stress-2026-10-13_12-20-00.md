# TraceFlow Stress Benchmark

## Test Configuration

| Parameter     | Value                   |
| ------------- | ----------------------- |
| Scenario      | stress                  |
| Virtual Users | 20                      |
| Duration      | 9 minutes               |
| Endpoint      | POST /ingestion/v1/logs |
| Environment   | performance             |

## Thresholds

| Metric      | Threshold |
| ----------- | --------- |
| Error rate  | < 1%      |
| p95 latency | < 500 ms  |

## Results

| Metric         |         Result |
| -------------- | -------------: |
| Total requests |        960,669 |
| Throughput     | 1,778.99 req/s |
| p50 latency    |        7.89 ms |
| p90 latency    |        9.24 ms |
| p95 latency    |        9.77 ms |
| Error rate     |          0.00% |

## Threshold Evaluation

| Metric      |  Result | Status |
| ----------- | ------: | ------ |
| Error rate  |   0.00% | PASS   |
| p95 latency | 9.77 ms | PASS   |

## Observations

* Hệ thống xử lý **960.669 request** trong thời gian **9 phút**, với tối đa **20 VUs**.
* Throughput đạt khoảng **1.778,99 req/s**.
* Độ trễ **p50 là 7,89 ms**, **p90 là 9,24 ms** và **p95 là 9,77 ms**.
* Tỷ lệ lỗi HTTP là **0,00%**, toàn bộ request đều thành công.
* Cả hai threshold về **error rate** và **p95 latency** đều đạt yêu cầu.
* So với `test-002`, stress throughput tăng mạnh và p95 latency giảm sâu.
