# TraceFlow Stress Benchmark

## Test Configuration

| Parameter     | Value                   |
| ------------- | ----------------------- |
| Scenario      | stress                  |
| Virtual Users | 20                      |
| Duration      | 9 minutes               |
| Endpoint      | POST /ingestion/v1/logs |
| Environment   | performance             |

## Thresholds

| Metric      | Threshold |
| ----------- | --------- |
| Error rate  | < 1%      |
| p95 latency | < 500 ms  |

## Results

| Metric         |       Result |
| -------------- | -----------: |
| Total requests |      430,971 |
| Throughput     | 798.09 req/s |
| p50 latency    |      8.48 ms |
| p90 latency    |     65.04 ms |
| p95 latency    |     77.07 ms |
| Error rate     |        0.00% |

## Threshold Evaluation

| Metric      |   Result | Status |
| ----------- | -------: | ------ |
| Error rate  |    0.00% | PASS   |
| p95 latency | 77.07 ms | PASS   |

## Observations

* Hệ thống xử lý **430.971 request** trong thời gian **9 phút**, với tối đa **20 VUs**.
* Throughput đạt khoảng **798,09 req/s**.
* Độ trễ **p50 là 8,48 ms**, **p90 là 65,04 ms** và **p95 là 77,07 ms**.
* Tỷ lệ lỗi HTTP là **0,00%**, toàn bộ request đều thành công.
* Cả hai threshold về **error rate** và **p95 latency** đều đạt yêu cầu.
* So với test-001, throughput thấp hơn, nhưng **p95 latency giảm từ 87,50 ms xuống 77,07 ms**, cho thấy tail latency cải thiện nhẹ trong kịch bản stress.
