# TraceFlow Spike Benchmark

## Test Configuration

| Parameter     | Value                   |
| ------------- | ----------------------- |
| Scenario      | spike                   |
| Virtual Users | 50                      |
| Duration      | 5 minutes 30 seconds    |
| Endpoint      | POST /ingestion/v1/logs |
| Environment   | performance             |

## Thresholds

| Metric      | Threshold |
| ----------- | --------- |
| Error rate  | < 1%      |
| p95 latency | < 500 ms  |

## Results

| Metric         |       Result |
| -------------- | -----------: |
| Total requests |      174,747 |
| Throughput     | 529.46 req/s |
| p50 latency    |      9.13 ms |
| p90 latency    |     88.06 ms |
| p95 latency    |     92.52 ms |
| Error rate     |        0.00% |

## Threshold Evaluation

| Metric      |   Result | Status |
| ----------- | -------: | ------ |
| Error rate  |    0.00% | PASS   |
| p95 latency | 92.52 ms | PASS   |

## Observations

* Hệ thống xử lý **174.747 request** trong thời gian **5 phút 30 giây**, với tối đa **50 VUs**.
* Throughput đạt khoảng **529,46 req/s**.
* Độ trễ **p50 là 9,13 ms**, **p90 là 88,06 ms** và **p95 là 92,52 ms**.
* Tỷ lệ lỗi HTTP là **0,00%**, toàn bộ request đều nhận HTTP 200.
* Cả hai threshold về **error rate** và **p95 latency** đều đạt yêu cầu.
* Khác với test-001, spike benchmark lần này là kết quả hợp lệ vì không còn tình trạng **100,00% request thất bại**.
