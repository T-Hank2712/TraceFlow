# TraceFlow Load Benchmark

## Test Configuration

| Parameter     | Value                   |
| ------------- | ----------------------- |
| Scenario      | load                    |
| Virtual Users | 10                      |
| Duration      | 5 minutes               |
| Endpoint      | POST /ingestion/v1/logs |
| Environment   | performance             |

## Thresholds

| Metric      | Threshold |
| ----------- | --------- |
| Error rate  | < 1%      |
| p95 latency | < 500 ms  |

## Results

| Metric         |       Result |
| -------------- | -----------: |
| Total requests |      269,499 |
| Throughput     | 898.31 req/s |
| p50 latency    |      7.70 ms |
| p90 latency    |      9.45 ms |
| p95 latency    |     13.12 ms |
| Error rate     |        0.00% |

## Threshold Evaluation

| Metric      |   Result | Status |
| ----------- | -------: | ------ |
| Error rate  |    0.00% | PASS   |
| p95 latency | 13.12 ms | PASS   |

## Observations

* Hệ thống xử lý **269.499 request** trong thời gian **5 phút**, với tối đa **10 VUs**.
* Throughput đạt khoảng **898,31 req/s**.
* Độ trễ **p50 là 7,70 ms**, **p90 là 9,45 ms** và **p95 là 13,12 ms**.
* Tỷ lệ lỗi HTTP là **0,00%**, không có request thất bại.
* Cả hai threshold về **error rate** và **p95 latency** đều đạt yêu cầu.
* So với test-001, throughput thấp hơn, nhưng **p95 latency giảm từ 82,24 ms xuống 13,12 ms**, cho thấy độ trễ đuôi ổn định hơn trong kịch bản load.
