# TraceFlow Capacity Benchmark Before Resource Upgrade

## Test Configuration

| Parameter   | Value                   |
| ----------- | ----------------------- |
| Scenario    | capacity                |
| Executor    | constant-arrival-rate   |
| Duration    | 2 minutes               |
| Endpoint    | POST /ingestion/v1/logs |
| Environment | performance             |
| Resource    | before resource upgrade |

## Thresholds

| Metric      | Threshold |
| ----------- | --------- |
| Error rate  | < 1%      |
| p95 latency | < 500 ms  |

## Threshold Evaluation

| Target RPS | Error rate result | Error rate status | p95 latency result | p95 latency status |
| ---------: | ----------------: | ----------------- | -----------------: | ------------------ |
|      1,000 |             0.00% | PASS              |           16.20 ms | PASS               |
|      1,200 |             0.58% | PASS              |          179.85 ms | PASS               |
|      1,300 |             0.00% | PASS              |           85.48 ms | PASS               |
|      2,000 |             0.64% | PASS              |           34.94 ms | PASS               |

## Observations

* Các mốc **1.000 RPS**, **1.200 RPS**, **1.300 RPS** và **2.000 RPS** đều đạt threshold cấu hình hiện tại.
* Mốc **1.000 RPS** là mốc sạch nhất trong nhóm resource cũ: error rate **0,00%**, p95 latency **16,20 ms**.
* Mốc **1.200 RPS** vẫn PASS nhưng có dấu hiệu căng hơn: error rate **0,58%**, p95 latency tăng lên **179,85 ms** và dropped iterations đạt **907**.
* Mốc **1.300 RPS** ổn định hơn mốc 1.200 RPS trong lần chạy này, với chỉ **1 request không đạt HTTP 200** trên tổng **155.687 request**.
* Mốc **2.000 RPS** vẫn PASS nhưng error rate đạt **0,64%**, cho thấy hệ thống đã có lỗi nhẹ dù p95 latency vẫn thấp.
* Không có file tổng kết `capacity-1500.txt` trong bộ kết quả hiện tại, nên mốc 1.500 RPS không được đưa vào bảng này.
* Nhóm kết quả này nên được xem là baseline trước khi tăng resource, không trộn trực tiếp với các mốc capacity sau khi nâng cấp resource.

## Summary

Trước khi nâng cấp resource, hệ thống vẫn có thể PASS tới **2.000 RPS** theo threshold `< 1% error` và `p95 < 500 ms`, nhưng các mốc từ **1.200 RPS** trở lên đã bắt đầu xuất hiện lỗi hoặc dropped iterations đáng chú ý. Mốc phù hợp để xem là ổn định sạch trong nhóm này là khoảng **1.000 RPS - 1.300 RPS**, tùy tiêu chí chấp nhận lỗi.
