# TraceFlow Stress Benchmark

## Test Configuration

| Parameter     | Value                   |
| ------------- | ----------------------- |
| Scenario      | stress                  |
| Virtual Users | 20                      |
| Duration      | 9 minutes               |
| Endpoint      | POST /ingestion/v1/logs |
| Environment   | performance             |

## Thresholds

| Metric      | Threshold |
| ----------- | --------- |
| Error rate  | < 1%      |
| p95 latency | < 500 ms  |

## Results

| Metric         |         Result |
| -------------- | -------------: |
| Total requests |        668,662 |
| Throughput     | 1,238.26 req/s |
| p50 latency    |        1.66 ms |
| p90 latency    |       82.50 ms |
| p95 latency    |       87.50 ms |
| Error rate     |          0.00% |

## Threshold Evaluation

| Metric      |   Result | Status |
| ----------- | -------: | ------ |
| Error rate  |    0.00% | PASS   |
| p95 latency | 87.50 ms | PASS   |

## Observations

* Hệ thống xử lý **668.662 request** với tối đa **20 VUs**.
* Throughput đạt khoảng **1.238,26 req/s**.
* p50 latency đạt **1,66 ms**.
* p90 latency đạt **82,50 ms**.
* p95 latency đạt **87,50 ms**, thấp hơn threshold 500 ms.
* HTTP error rate là **0,00%**, toàn bộ 668.662 request đều thành công.
* Cả hai threshold của load benchmark đều **PASS**.
