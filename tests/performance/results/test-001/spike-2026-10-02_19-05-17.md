# TraceFlow Spike Benchmark

## Test Configuration

| Parameter     | Value                   |
| ------------- | ----------------------- |
| Scenario      | spike                   |
| Virtual Users | 50                      |
| Duration      | 5 minutes               |
| Endpoint      | POST /ingestion/v1/logs |
| Environment   | performance             |

## Thresholds

| Metric      | Threshold |
| ----------- | --------- |
| Error rate  | < 1%      |
| p95 latency | < 500 ms  |

## Results

| Metric         |         Result |
| -------------- | -------------: |
| Total requests |      1,404,104 |
| Throughput     | 4,254.86 req/s |
| p50 latency    |       0.233 ms |
| p90 latency    |        1.03 ms |
| p95 latency    |        2.10 ms |
| Error rate     |        100.00% |

## Threshold Evaluation

| Metric      |  Result | Status |
| ----------- | ------: | ------ |
| Error rate  | 100.00% | FAIL   |
| p95 latency | 2.10 ms | PASS   |

## Observations

* Hệ thống thực hiện **1.404.104 request** với tối đa **50 VUs**.
* Throughput đạt khoảng **4.254,86 req/s**.
* p50 latency đạt **0,233 ms**.
* p90 latency đạt **1,03 ms**.
* p95 latency đạt **2,10 ms**, thấp hơn threshold 500 ms.
* Tuy nhiên, **100,00% request thất bại**; toàn bộ 1.404.104 request đều không nhận được HTTP 200.
* Vì vậy, **error rate threshold FAIL** và stress benchmark này **không thể được xem là một kết quả stress test thành công**, dù latency và throughput đo được rất cao.
