# TraceFlow Load Benchmark

## Test Configuration

| Parameter     | Value                   |
| ------------- | ----------------------- |
| Scenario      | load                    |
| Virtual Users | 10                      |
| Duration      | 5 minutes               |
| Endpoint      | POST /ingestion/v1/logs |
| Environment   | performance             |

## Thresholds

| Metric      | Threshold |
| ----------- | --------- |
| Error rate  | < 1%      |
| p95 latency | < 500 ms  |

## Results

| Metric         |         Result |
| -------------- | -------------: |
| Total requests |        362,773 |
| Throughput     | 1,209.27 req/s |
| p50 latency    |        1.01 ms |
| p90 latency    |        2.28 ms |
| p95 latency    |       82.24 ms |
| Error rate     |          0.00% |

## Threshold Evaluation

| Metric      |   Result | Status |
| ----------- | -------: | ------ |
| Error rate  |    0.00% | PASS   |
| p95 latency | 82.24 ms | PASS   |

## Observations

* Hệ thống xử lý **362.773 request** trong thời gian **5 phút**, với tối đa **10 VUs**.
* Throughput đạt khoảng **1.209,27 req/s**.
* Độ trễ **p50 là 1,01 ms**, **p90 là 2,28 ms** và **p95 là 82,24 ms**.
* Tỷ lệ lỗi HTTP là **0,00%**, không có request thất bại.
* Cả hai threshold về **error rate** và **p95 latency** đều đạt yêu cầu.
* So với baseline, **p95 latency tăng từ 2,56 ms lên 82,24 ms** khi tải tăng lên 10 VUs, trong khi error rate vẫn duy trì ở **0,00%**.
