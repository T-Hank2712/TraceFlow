# TraceFlow Spike Benchmark

## Test Configuration

| Parameter | Value |
| --- | --- |
| Scenario | spike |
| Virtual Users | Ramp 10 -> 50 -> 10 VUs |
| Duration | 5 minutes 30 seconds |
| Endpoint | `POST /ingestion/v1/logs` |
| Environment | performance |

## Thresholds

| Metric | Threshold |
| --- | --- |
| Error rate | < 1% |
| p95 latency | < 500 ms |

## Results

| Metric | Result |
| --- | ---: |
| Total requests | 524,906 |
| Throughput | 1,590.60 req/s |
| Average latency | 10.19 ms |
| p50 latency | 7.75 ms |
| p90 latency | 9.66 ms |
| p95 latency | 11.40 ms |
| Maximum latency | 396.27 ms |
| Error rate | 0.00% |

## Threshold Evaluation

| Metric | Result | Status |
| --- | ---: | --- |
| Error rate | 0.00% | PASS |
| p95 latency | 11.40 ms | PASS |

## Observations

* Hệ thống xử lý 524.906 request khi tăng nhanh từ 10 lên 50 VUs rồi giảm về 10 VUs.
* Không có HTTP request hoặc check nào thất bại trong lúc spike.
* p95 đạt 11,40 ms, vẫn dưới ngưỡng nghiêm ngặt 20 ms.
* Maximum latency 396,27 ms cho thấy có outlier khi tải thay đổi, nhưng dưới 5% request bị ảnh hưởng nên p95 vẫn ổn định.
