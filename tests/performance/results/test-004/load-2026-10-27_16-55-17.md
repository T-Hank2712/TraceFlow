# TraceFlow Load Benchmark

## Test Configuration

| Parameter | Value |
| --- | --- |
| Scenario | load |
| Virtual Users | Ramp from 1 to 10 VUs |
| Duration | 5 minutes |
| Endpoint | `POST /ingestion/v1/logs` |
| Environment | performance |

## Thresholds

| Metric | Threshold |
| --- | --- |
| Error rate | < 1% |
| p95 latency | < 500 ms |

## Results

| Metric | Result |
| --- | ---: |
| Total requests | 312,496 |
| Throughput | 1,041.63 req/s |
| Average latency | 7.67 ms |
| p50 latency | 7.46 ms |
| p90 latency | 8.71 ms |
| p95 latency | 9.25 ms |
| Maximum latency | 177.67 ms |
| Error rate | 0.00% |

## Threshold Evaluation

| Metric | Result | Status |
| --- | ---: | --- |
| Error rate | 0.00% | PASS |
| p95 latency | 9.25 ms | PASS |

## Observations

* Hệ thống xử lý 312.496 request trong 5 phút với throughput trung bình 1.041,63 req/s.
* Không có HTTP request hoặc check nào thất bại.
* p95 là 9,25 ms, thấp hơn cả threshold benchmark 500 ms và ngưỡng nghiêm ngặt 20 ms.
* Maximum latency 177,67 ms là một outlier đơn lẻ; không làm ảnh hưởng tail latency p95.
